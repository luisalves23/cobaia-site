o problema

Por que isso não existia antes

Lembra quando cada aparelho tinha um plugue diferente e a gaveta de casa era cheia de adaptador? Com a IA era assim. Pra ligar o Claude no Canva, alguém programava uma ponte. Pra ligar no e-mail, outra. Se aparecesse outra IA, tudo de novo. O MCP virou a tomada padrão, e o Claude só precisa encaixar.

Aperte o botão e veja a diferença.

por que os rivais entraram

O padrão é aberto

A Anthropic publicou o MCP como padrão aberto: qualquer empresa pode fazer a sua tomada sem pedir licença. Quanto mais apps falam MCP, mais vale a pena pra qualquer IA usar também. Por isso a fila andou rápido.

palavras do vídeo

Glossário rápido

MCP
Model Context Protocol. O padrão que diz como uma IA conversa com um app.
Servidor MCP
A "tomada" de um app. É o que o app publica pra qualquer IA compatível poder usar.
Conector
O nome que o Claude dá pra um app ligado. Quase todos funcionam por MCP.
Ferramenta
Cada item do cardápio: uma ação que o app deixa a IA fazer, como "buscar e-mail".

dúvidas dos comentários

Perguntas frequentes

Preciso saber programar?

Não. Programar só é preciso se você quiser criar a tomada de um app que ainda não tem. Pra usar os conectores prontos, é clicar e autorizar.

Funciona em qual plano?

Eu não sei dizer qual plano tem o quê, isso muda com o tempo. Se a opção de conectores não aparecer pra você, confira a página de conectores na ajuda do Claude. Você também precisa de uma conta do Canva.

MCP é a mesma coisa que conector?

Quase. O MCP é o padrão por baixo. O conector é o botão que você vê no Claude. Um usa o outro.

Se a OpenAI usa, o ChatGPT vira o Claude?

Não. Cada IA continua sendo uma IA diferente. O que fica igual é a tomada: o mesmo app pode ser ligado em várias delas.
