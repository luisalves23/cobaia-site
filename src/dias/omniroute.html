entenda antes de instalar

O que o OmniRoute faz de verdade

Pense numa central telefônica. O Claude Code é o telefone. Normalmente ele liga direto pra Anthropic. Com o OmniRoute, ele liga pra central que roda no seu computador, e a central passa a ligação pra quem estiver disponível: uma conta grátis do Gemini, o Groq, o OpenRouter, a sua assinatura, um modelo rodando no seu próprio PC.

  1. 1
    Um endereço pra tudoTodo programa que aceita "endereço compatível com OpenAI" ou com a API da Anthropic passa a usar http://localhost:20128. Você configura as chaves uma vez, num painel, e não em cada ferramenta.
  2. 2
    Troca automática (fallback)Se a IA da vez dá erro, estoura o limite ou fica lenta, ele passa o pedido pra próxima da lista sem você fazer nada. É isso que faz as cotas grátis renderem.
  3. 3
    Modelo "auto"Em vez de escolher a IA, você pede o modelo auto e ele decide entre as que você ligou. Tem variações como auto/coding, auto/fast e auto/cheap.
  4. 4
    Painel com o gastoMostra quanto cada IA usou, quanto de cota grátis sobrou e quais estão fora do ar.
!

Sobre o "352": é o número do site oficial. O repositório no GitHub já fala em 394, porque eles contam de jeitos diferentes (chat, imagem, áudio, busca, modelos locais). A conta muda toda semana. O que importa é que tem muita opção, e várias com plano grátis.

antes de começar

O que você vai precisar

  • Um computador com Windows, Mac ou Linux. Dá pra rodar até no Android, pelo Termux, mas comece pelo computador.
  • O Node.js 22 ou 24 (versão LTS). Baixe em nodejs.org. Versões antigas, como a 18 ou a 20, não servem.
  • O Claude Code instalado (o comando está no passo 4).
  • Uma conta em pelo menos um provedor grátis. O mais simples pra começar é a chave do Google AI Studio (Gemini).
!

Não precisa de cartão pra começar, mas alguns provedores pedem (o Cerebras, por exemplo, só libera o crédito grátis com cartão cadastrado). Se pedirem cartão e você não quiser, pule pro próximo da lista.

o passo a passo

Da instalação ao Claude Code rodando

1

Confira o Node.js

No Windows, abra o PowerShell; no Mac ou Linux, o Terminal. Digite node -v. Se aparecer v22 ou v24, siga. Se der erro ou mostrar outra versão, instale o LTS pelo nodejs.org e abra o terminal de novo.

2

Instale o OmniRoute

Cole o comando abaixo. Avisos amarelos de npm warn são normais e podem ser ignorados.

Terminal · instalar
npm install -g omniroute
!

Deu erro falando de "scripts" ou "allow-scripts"? Isso acontece no npm 11 ou mais novo, que bloqueia os scripts de instalação. O OmniRoute precisa deles. Use este comando no lugar (se o aviso do npm citar outros nomes, troque pelos nomes que ele mostrar):

Só se der erro · npm 11
npm install -g --allow-scripts=omniroute,keytar,onnxruntime-node,@parcel/watcher,@swc/core,protobufjs,esbuild omniroute
3

Ligue o servidor

Digite omniroute e deixe essa janela aberta. Enquanto ela estiver aberta, o OmniRoute está funcionando. Abra o painel no navegador: http://localhost:20128/dashboard.

Terminal · ligar (deixe aberto)
omniroute
4

Instale o Claude Code (se ainda não tem)

Abra outra janela de terminal, porque a primeira está ocupada com o servidor. Cole o comando do seu sistema.

Windows · PowerShell
irm https://claude.ai/install.ps1 | iex
Mac e Linux · Terminal
curl -fsSL https://claude.ai/install.sh | bash
5

Ligue pelo menos uma IA

No painel: Providers → + Add Provider → escolha o provedor → cole a chave dele (ou faça o login que ele pedir). A lista das que valem a pena está na próxima seção.

6

Abra o Claude Code pelo OmniRoute

Na segunda janela, digite o comando abaixo. Ele confere se o servidor está de pé, coloca o endereço e a chave certos e abre o Claude Code já apontado pro OmniRoute, sem mexer na sua configuração normal.

Terminal · abrir o Claude Code
omniroute launch
7

Teste com um pedido simples

Dentro do Claude Code, peça algo pequeno, como "crie um arquivo ola.txt escrito oi". Depois olhe no painel do OmniRoute qual IA respondeu.

o que você veio buscar

As IAs grátis que valem ligar

Ligue duas ou três, não uma só. É a soma delas, com a troca automática, que faz o grátis aguentar uma tarde de trabalho.

  1. 1
    Gemini (Google AI Studio)O começo mais fácil: entra com a conta Google, gera uma chave em aistudio.google.com e cola no painel. Os limites variam por modelo e por projeto.
  2. 2
    GroqMuito rápido. Conta grátis em console.groq.com, gera a chave e cola. Tem limite por minuto, então funciona melhor como reserva.
  3. 3
    OpenRouter (modelos ":free")Um catálogo grande de modelos com final :free. A cota grátis é dividida com todo mundo e acaba rápido em horário de pico.
  4. 4
    NVIDIA NIMModelos como GLM e MiniMax, com cerca de 40 pedidos por minuto grátis.
  5. 5
    Pollinations e OpenCode FreeNão pedem chave nenhuma. Bons pra testar se tudo está ligado, mas a disponibilidade oscila e alguns recusam programas de terceiros.
  6. 6
    Ollama ou LM Studio (no seu PC)O modelo roda no seu próprio computador: grátis de verdade e nada sai da sua máquina. Precisa de um PC com memória e placa de vídeo boas; em máquina fraca fica lento demais pro Claude Code.
!

No painel tem a página /dashboard/free-tiers, que mostra quanto de cota grátis você ainda tem em cada IA ligada. Olhe ela antes de reclamar que "parou de funcionar".

pra ir além

Escolher a IA na mão

O omniroute launch usa o modo automático. Se você quer fixar uma IA, tem dois jeitos:

Jeito rápido · uma IA só, nesta sessão
omniroute run claude --model [provedor/modelo]

Troque [provedor/modelo] por um nome da lista de modelos do painel, no formato provedor/modelo (por exemplo glm/glm-5.2).

Jeito com perfis · um atalho por IA
omniroute setup-claude
omniroute launch --profile [nome-do-perfil]

O setup-claude cria um perfil pra cada modelo que você ligou (nomes como glm52 ou kimi-k27), sem mexer na sua configuração normal do Claude Code. Use omniroute setup-claude --dry-run pra ver o que ele vai criar antes.

Quero configurar à mão, sem o comando launch

O Claude Code lê três variáveis quando abre. Pegue a chave em Dashboard → Endpoints e, no Mac ou Linux, rode antes de abrir o claude:

Mac e Linux · manual
export ANTHROPIC_BASE_URL=http://localhost:20128
export ANTHROPIC_AUTH_TOKEN=[SUA CHAVE DO OMNIROUTE]
export ANTHROPIC_MODEL=[provedor/modelo]
claude

O endereço vai sem o /v1 no final; com ele, não funciona. As variáveis só valem na hora em que o Claude Code abre: mudou alguma, feche e abra de novo.

Como confiro se o servidor está respondendo?

Com o omniroute rodando, este comando lista as IAs ligadas. Se aparecer a lista, está tudo certo:

Terminal · teste
curl http://localhost:20128/v1/models -H "Authorization: Bearer [SUA CHAVE]"

o que ninguém te conta

Os limites, sem enfeite

  1. 1
    Grátis não é Claude de graçaO Claude Code é só a ferramenta. Com as IAs grátis, quem pensa é outro modelo. Muitos são bons pra tarefas simples, mas em projeto grande você vai notar a diferença: erram mais, se perdem em arquivos longos e às vezes não sabem usar as ferramentas do Claude Code direito.
  2. 2
    Instalar não bastaO próprio projeto avisa: numa instalação nova pode não ter nenhuma IA disponível. Sem ligar pelo menos um provedor, o Claude Code abre e não recebe resposta.
  3. 3
    As cotas mudam toda semanaOs números de "tokens grátis por mês" são uma estimativa somando várias contas diferentes, não um presente do OmniRoute. Cada provedor pode cortar o grátis quando quiser.
  4. 4
    Janela de contextoO Claude Code acha que todo modelo desconhecido aguenta 200 mil tokens. Se o modelo que você escolheu aguenta menos, a conversa quebra no meio. Os perfis do setup-claude já acertam isso pra você; mais um motivo pra usar.
  5. 5
    É um programa grandeTem painel, banco de dados, servidor de MCP, compressão e muito mais. Você não precisa de quase nada disso pra começar. Ignore o resto até o básico funcionar.

cuidados

Leia antes de usar no trabalho

  1. 1
    Seu código vai pra quem respondeAs chaves ficam guardadas criptografadas no seu computador, mas o pedido em si vai pro provedor escolhido. Vários planos grátis podem usar o que você manda pra treinar modelos, e alguns registram todos os pedidos. Não mande senha, dado de cliente ou código da empresa por IA grátis.
  2. 2
    Cuidado com os provedores "Web"Opções como ChatGPT Web, Claude Web e Gemini Web usam o login do seu navegador, e isso pode ir contra os termos desses serviços. O próprio OmniRoute marca alguns provedores como "avoid" e tira eles do modo automático. Se usar, é por sua conta e risco de bloqueio da conta.
  3. 3
    Não crie contas extras pra furar limiteOs termos da maioria dos provedores proíbem, e você pode perder todas.
  4. 4
    Deixe só no seu computadorUse pelo endereço localhost. Não libere a porta 20128 no roteador nem rode num servidor público sem senha: quem achar o endereço usa as suas chaves e gasta as suas cotas.
  5. 5
    Baixe só do lugar oficialO pacote no npm é omniroute, o site é omniroute.online e o código está em github.com/cheaper-inference/OmniRoute. Fuja de "versão premium" ou instalador vindo de link de terceiro.

dúvidas dos comentários

Perguntas frequentes

O OmniRoute é de graça mesmo?

Sim. O programa é open source, licença MIT, e roda no seu computador sem assinatura. Existe uma versão hospedada paga (OmniRoute Cloud), mas você não precisa dela. O que pode custar dinheiro são as IAs pagas, se você ligar alguma.

Vou usar o Claude de graça?

Não. Com as opções grátis você usa a ferramenta do Claude Code com outros modelos. Pra o Claude responder, você precisa ligar uma conta ou chave da Anthropic, e aí paga normalmente.

Preciso do plano Pro do Claude?

Pra usar o Claude Code com as IAs do OmniRoute, não: ele usa a chave do OmniRoute no lugar do login da Anthropic. Se quiser o modelo Claude no meio da lista, aí sim precisa de assinatura ou chave da Anthropic.

Fechei o terminal e parou tudo. Por quê?

O servidor só funciona com a janela do omniroute aberta. Abra de novo e deixe rodando. Existe versão de desktop e Docker pra ficar sempre ligado, mas pra começar o terminal basta.

Funciona com outras ferramentas além do Claude Code?

Sim: Codex, Cursor, Cline, Aider, OpenCode, Gemini CLI e qualquer programa que aceite um endereço compatível com OpenAI. Pra esses, use http://localhost:20128/v1 (agora com o /v1), a chave do painel e o modelo auto.

Deu "Ambiguous model" no Claude Code. E agora?

Acontece quando você ligou duas contas do Claude ao mesmo tempo e o OmniRoute não sabe qual usar. Escolha o modelo com o nome completo (com o prefixo do provedor), como no passo "Escolher a IA na mão".

Roda no celular?

Roda no Android pelo Termux (pkg install nodejs && npx -y omniroute), mas pra usar com o Claude Code o caminho mais tranquilo é o computador.
