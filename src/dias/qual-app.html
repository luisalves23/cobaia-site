instalar pelo Flathub

Liga a loja de apps uma vez

O Flathub é a loja de apps que funciona em qualquer Linux. Ligue uma vez e depois é só procurar e instalar.

Ligar o Flathub
sudo apt install -y flatpak
flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

Reinicie o notebook. Depois, pra instalar um app, procure o nome dele e instale (exemplo com o Spotify):

Procurar e instalar
flatpak search spotify
flatpak install -y flathub com.spotify.Client

O nome comprido (com.spotify.Client) aparece no resultado da busca. Copie de lá.
